## 2026-03-31 - SQL Injection in Metadata Table Population
**Vulnerability:** String-interpolated f-strings were used to insert runtime values (`dataReferencia` and `qtde_cnpjs`) into the `_referencia` metadata table via `engine.execute(text(f"insert into _referencia ..."))`. If extracted file paths or inputs contain crafted SQL statements or unexpected quote characters, this creates a SQL injection vector.
**Learning:** Even internal metadata or parsed values from files/counts should never be concatenated directly into SQL statements using f-strings. In SQLAlchemy, `text()` statements must use bind parameters (e.g. `:ref`, `:val`) and pass dictionaries of parameters to guarantee proper escaping and parameterized execution.
**Prevention:** Always parameterize queries with SQLAlchemy `text()` and bind parameter dictionaries (e.g., `engine.execute(text("insert into ... values (:ref, :val)"), {"ref": ..., "val": ...})`). Avoid f-string or `%` interpolation for values in SQL execution.
